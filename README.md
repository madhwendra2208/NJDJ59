# Salesforce-inspired responsive website UI clone
This project is a Salesforce-inspired responsive website UI clone built using HTML and CSS. It demonstrates modern web design practices by replicating the look and feel of Salesforce’s homepage with multiple sections, navigation, and interactive styling.

Styling (style.css)

Custom responsive design with Flexbox layout.

Hover effects on navigation, buttons, and product cards.

Box shadows, rounded corners, and clean typography for a modern UI feel.

🎯 Objective

The main objective of this project was to practice front-end development skills by recreating a professional-looking webpage with proper layouts, responsive design, and reusable components. It serves as a beginner-friendly web development project showcasing how to structure multi-page websites with HTML and CSS only.
